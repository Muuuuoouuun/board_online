# 04. 디자인 시스템 — 아이덴티티, 토큰, 보드 아트 디렉션

> 자산을 실제로 어떤 모델·도구로 만드는지는 `docs/08-asset-pipeline.md` 참고.

## 1. 비주얼 컨셉

> **"조용한 탁자 위의 게임판."** UI는 따뜻한 종이색 배경에 절제된 무채색 크롬. 색과 질감은 게임판에만 집중시켜 보드가 항상 화면의 주인공이 되게 한다.

- 플랫폼 크롬(내비, 버튼, 카드)은 **하나의 액센트 색**만 쓴다. 게임별 색은 보드 스킨 토큰으로 분리한다.
- 나무·돌·천 같은 재질 느낌은 **은은한 그라데이션과 노이즈 정도**로만 표현한다. 사진 텍스처, 3D 렌더, 스큐어모픽 그림자는 쓰지 않는다 (무겁고, 다크 모드와 충돌하고, 타 서비스와 비슷해진다).
- 한국 전통 게임에는 **오방색 계열(적·청·황)의 액센트**를 보드 스킨에서만 쓴다. 장기의 초(청)·한(적)이 자연스러운 출발점.
- 모든 화면에서 "지금 누구 차례인가"와 "마지막 수가 어디인가"가 1초 안에 보여야 한다.

## 2. 디자인 토큰 (`packages/ui/tokens.css`)

CSS 변수로 정의하고 Tailwind 테마에 매핑한다. **어떤 색도 컴포넌트 안에 하드코딩하지 않는다.**

```css
:root {

  --bg:            #F5F1EA;   /* 따뜻한 종이색 */
  --surface:       #FFFFFF;
  --surface-2:     #EDE8DF;
  --border:        #D9D2C5;

  /* 텍스트 */
  --fg:            #1C1917;
  --fg-muted:      #6B655C;
  --fg-subtle:     #9C958A;

  /* 액센트 (인터랙션 전용, 플랫폼에서 단 하나) */
  --accent:        #0F766E;   /* 청록 */
  --accent-fg:     #FFFFFF;
  --accent-hover:  #115E59;
  --accent-soft:   #CCFBF1;

  /* 시맨틱 */
  --success:       #15803D;
  --warning:       #B45309;
  --danger:        #B91C1C;
  --info:          #1D4ED8;

  /* 보드 하이라이트 (게임 공통, 색약 대응 위해 형태와 함께 사용) */
  --hl-last-move:  rgba(234, 179, 8, 0.45);   /* 노랑 반투명 */
  --hl-legal:      rgba(15, 118, 110, 0.55);  /* 액센트 점 */

  --board-wood:        #D9B26A;  /* 바둑·장기·고누판 */
  --board-wood-line:   #3F2E12;
  --board-light:       #EFE3C8;  /* 체스·체커 밝은 칸 */
  --board-dark:        #A9825A;  /* 체스·체커 어두운 칸 */

  --piece-white:   #F4F1EA;
  --piece-red:     #B3261E;   /* 장기 한 */
  --piece-green:   #1F6F4E;   /* 장기 초 */

  --shadow-md: 0 4px 12px rgba(0,0,0,.08);
}

@media (prefers-color-scheme: dark) { :root:not([data-theme="light"]) { /* 아래 dark 블록과 동일 */ } }
:root[data-theme="dark"] {
  --bg: #15130F; --surface: #1E1B16; --surface-2: #26221C; --border: #3A342B;
  --fg: #EDE8E0; --fg-muted: #A79F92; --fg-subtle: #736B5E;

```

## 4. 레이아웃

### 대국 화면 (핵심)

```
데스크톱 (≥ 1024px)                         모바일 (< 768px)
┌────────────────────────┬─────────────┐   ┌──────────────────────┐
│                        │ 상대 카드    │   │ 상대 카드 · 시계       │
│                        │ + 시계      │   ├──────────────────────┤
│       보드 (정사각형,    │─────────────│   │                      │
│   높이 100vh-헤더에 맞춤) │ 수 목록      │   │   보드 (가로 100vw)   │
│                        │ (스크롤)     │   │                      │
│                        │─────────────│   ├──────────────────────┤
│                        │ 내 카드+시계  │   │ 내 카드 · 시계         │
│                        │ 액션 바      │   │ 액션 바 (기권·무승부·수) │
└────────────────────────┴─────────────┘   └──────────────────────┘
```

- 보드는 항상 뷰포트에 **잘리지 않는 최대 정사각형** (`min(100vw, 100vh - 고정 UI 높이)`). 스크롤로 보드를 찾게 만들지 않는다.
- 모바일에서 수 목록·설정은 바텀 시트. 액션 바 버튼 높이 48px 이상.
- 상대 카드는 위, 내 카드는 아래 (내 시점). 보드도 내 시점으로 회전(체스 흑이면 8열이 아래).

### 로비
- 게임 카드 그리드: 모바일 2열, 태블릿 3열, 데스크톱 4열. 카드에 게임 아이콘, 이름, 태그(전략/전통/운), 평균 시간, "빠른 대국".
- 상단 고정 영역에 "진행 중인 내 대국" (있을 때만).

### 반응형 브레이크포인트
`sm 640 / md 768 / lg 1024 / xl 1280`. 대국 화면은 768 기준으로 좌우→상하 전환.

## 5. 보드 렌더링 규칙 (모든 게임 공통)

- `<svg viewBox="0 0 N N">`, **1 단위 = 1칸**. 픽셀 계산을 컴포넌트 안에서 하지 않는다. 크기는 CSS가 정한다.
- SVG 안에는 `rect circle line path text g use symbol` 프리미티브만 쓴다. `foreignObject`·HTML 금지. (react-native-svg 이식 가능성 유지.)
- 말은 `<symbol id="piece-wK">`로 한 번 정의하고 `<use>`로 찍는다.
- 레이어 순서(아래→위): 판 바탕 → 격자/칸 → 좌표 라벨 → 하이라이트(마지막 수·선택) → 말 → 합법수 표시 → 드래그 중인 말 → 오버레이(장군 표시, 결과).
- 터치 히트 영역은 말보다 크게: 칸 전체 또는 교차점 반경 0.5 단위. 모바일에서 실제 픽셀 44px 이상이 되도록 보드 최소 크기를 보장.
- 입력 방식 셋 모두 지원: **탭-탭**(선택 후 목적지), **드래그**, **키보드**(방향키 이동 + Enter 선택/확정). 설정에 "착수 전 확인" 옵션(바둑·오목 기본 on, 모바일).
- 마지막 수는 항상 표시(칸 배경 또는 교차점 링). 장군/체크는 왕 주변 붉은 원형 그라데이션.
- 색만으로 정보를 구분하지 않는다: 합법수는 점, 잡기 가능은 링, 선택은 채움 — 색약 사용자도 형태로 구분.

## 6. 게임별 아트 디렉션

모든 말·판은 **직접 그린다**. 타 서비스의 말 세트, 판 색, 효과음을 참조해서 베끼지 않는다 (`06` 참고). 스타일은 "플랫, 두께 있는 외곽선 없음, 2톤 명암".

| 게임 | 판 | 말 | 포인트 |
|---|---|---|---|
| 체스 | 8×8, `--board-light/dark`. 좌표 a~h/1~8는 테두리 안쪽 작은 글자 | 스톤턴 형태(1849, 퍼블릭 도메인)를 참고한 **자체 실루엣**. 흑/백 2톤 + 1픽셀 대비선 | 승격 선택 UI는 보드 위 팝오버 |
| 장기 | 9×10 교차점, 궁성 대각선, `--board-wood`. 선은 진갈색 1.5px | 팔각형 말, 한자 1글자(왕은 楚/漢). 초=`--piece-green`, 한=`--piece-red`. 말 크기는 왕>차>포·마·상>사·졸 순으로 4단계 | 한글 표기 토글(車→차). 초기 마상 배치 선택 UI |
| 바둑 | 9/13/19 교차점, 화점 표시, `--board-wood` | 흑/백 원형 돌, 은은한 방사형 그라데이션으로 볼륨감. 그림자 없음 | 마지막 수 표시는 돌 위 작은 원. 사석 표시 단계에서 죽은 돌은 반투명+X |
| 오목 | 바둑판 15×15 재사용 | 바둑돌 재사용 | 승리 5목은 선으로 연결 강조 |
| 체커 | 체스판 재사용, 어두운 칸만 사용 | 원반 말, 킹은 이중 링 표시 | 강제 잡기 가능 말은 링 하이라이트 |
| 윷놀이 | 29점 윷판(원형 외곽 20 + 십자 내부 9). `--board-cloth` 위에 밝은 점·선. 모/방은 큰 점 | 팀별 말 4개(적/청), 업힌 말은 겹침+숫자 배지. 윷가락 4개는 던질 때 앞/뒤 뒤집힘 애니메이션 | 던지기 결과(도/개/걸/윷/모) 큰 글자 1초 노출. 남은 이동 큐를 칩으로 표시 |
| 고누 | 소형 그래프 판. 점과 선만, `--board-wood` | 바둑돌 재사용 소형 | 판이 작으므로 최소 320px 정사각형 보장 |
| 만칼라 | 가로형 2×6 + 좌우 창고, `--board-mancala` | 씨앗은 원 여러 개 대신 **숫자 + 최대 6개 점 아이콘**으로 표시 (가독성) | 뿌리기 애니메이션은 순차 0.06초 간격 |

게임 아이콘(로비 카드용): 24px 단색 글리프 8종을 직접 제작. 규칙: 2px 선, 둥근 끝, 정사각 안전 영역.

## 7. 컴포넌트 목록 (`packages/ui`)

공통 크롬: `Button`(primary/secondary/ghost/danger), `IconButton`, `Card`, `Dialog`, `Sheet`(모바일 바텀), `Tabs`, `Tooltip`, `Toast`, `Avatar`, `Badge`, `Select`, `Switch`, `Slider`.
플랫폼 전용: `PlayerCard`(아바타·이름·레이팅·접속 상태), `Clock`, `MoveList`, `ActionBar`, `GameCard`, `RatingChip`, `ResultBanner`, `PresetChat`.
보드 프리미티브: `BoardSurface`(viewBox·크기·스킨), `Grid`(칸형/교차형), `CoordLabels`, `Highlight`, `LegalDot`, `Piece`(symbol/use 래퍼), `DragLayer`, `useBoardInput`(탭·드래그·키보드 통합 훅).

UI 아이콘은 **Lucide**(ISC 라이선스). 게임 아이콘만 자체 제작.

## 8. 모션

- 말 이동: 120~180ms `ease-out`. 잡힌 말은 150ms 페이드+축소.
- 새 수 도착(상대): 이동 애니메이션 + 마지막 수 하이라이트 동시.
- 결과: 보드 위 배너가 아래에서 200ms 슬라이드. 보드를 가리지 않는다(결과 확인 뒤 리플레이 가능).
- 윷 던지기: 0.6초 이내. 결과 텍스트는 1초 후 자동 사라짐, 탭하면 즉시.
- `prefers-reduced-motion`이면 모든 이동 애니메이션을 즉시 전환으로 대체.
- 구현은 CSS transition 우선, 복합 시퀀스(뿌리기·던지기)만 Framer Motion.

## 9. 사운드

- 5종만: 착수, 잡기, 장군/체크, 종료(승/패/무 각각 톤 다르게), 저시간 경고.
- 파일은 직접 녹음·합성하거나 **CC0** 음원만 사용. 출처를 `packages/ui/sounds/LICENSES.md`에 기록.
- 기본값: 데스크톱 on, 모바일 off. 첫 사용자 제스처 후에만 재생(브라우저 자동재생 정책).

## 10. 접근성

- 모든 칸/교차점은 `role="button"` + `aria-label` ("e4, 흰 폰" / "Q16, 빈 점"). 보드는 `role="grid"`.
- 키보드만으로 대국 완주 가능. 포커스 링은 `--accent` 2px.
- 대비: 텍스트 4.5:1 이상, 말과 판 3:1 이상. 다크 모드도 동일 기준.
- 색약 모드 옵션: 장기 초/한을 청/적 대신 **형태(외곽 이중선)**로도 구분.
- 화면 리더용 수 알림: `aria-live="polite"` 영역에 "상대: 마 c3" 식으로 수 표기 텍스트 출력.
- 글자 크기 200% 확대 시 대국 화면 깨지지 않게 (수 목록은 스크롤, 보드는 축소).

## 11. 카피 톤

- 한국어는 해요체가 아닌 **간결한 평서체** ("기권하시겠어요?" 대신 "기권할까요?" / 버튼은 "기권").
- 게임 용어는 관용 표현을 따른다: 장군/멍군, 착수, 계가, 덤, 빽도, 잡기, 업기.
- 결과 문구는 사실만: "체크메이트 · 백 승", "시간 초과 · 흑 승", "합의 무승부".
