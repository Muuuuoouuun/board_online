# 06. IP 정책 — 저작권·상표 판단 기준과 체크리스트

> 이 문서는 법률 자문이 아니다. 상업 출시 전 IP 전문 변호사 검토를 받는다. 다만 아래 기준을 지키면 리스크의 대부분을 사전에 제거할 수 있다.

## 1. 기본 원칙

- **규칙·아이디어는 보호 대상이 아니다.** 한국저작권위원회와 WIPO 모두 "게임의 규칙·방법·절차는 아이디어이며 저작권 보호 대상이 아니다"라고 설명한다. 체스·바둑·장기 규칙을 직접 구현하는 것은 문제가 없다.
- **표현은 보호된다.** 타인이 만든 말 디자인, 판 그래픽, UI, 애니메이션, 효과음, 규칙 설명 문장, 소스코드는 저작물이다. 규칙이 같아도 이것을 베끼면 침해다.
- **이름·로고는 상표다.** 저작권과 별개로 등록 상표(예: 오델로, 카탄, 스플렌더)를 서비스명·게임명에 쓰면 상표 문제가 된다.
- **현대 상업 보드게임은 통째로 온라인화하지 않는다.** 메커니즘의 추상적 아이디어만 가져와 세계관·명칭·구성·밸런스·아트·텍스트를 새로 설계한 오리지널 게임은 별도 트랙(Phase 3)에서 검토한다.

## 2. 티어

| 티어 | 기준 | 조치 |
|---|---|---|
| 🟢 Green | 수백 년 이상 된 전통·고전 게임. 특정 권리자 없음 | 바로 구현. 표현물은 전부 자체 제작 |
| 🟡 Yellow | 규칙은 자유롭지만 (a) 특정 명칭이 상표이거나 (b) 20세기 중반 이후 발명이거나 (c) 특정 회사와 강하게 연결됨 | 명칭 검색(KIPRIS, USPTO) 후 일반명 사용. 판·말 디자인 독자화. 필요 시 자문 |
| 🔴 Red | 현대 상업 보드게임 (이름·아트·카드 텍스트·구성이 특정 회사 제품) | 라이선스 계약 없이는 구현하지 않음 |

| 게임 | 티어 | 주의점 |

| 체커 | 🟢 | "Checkers/Draughts" 일반명 |

## 4. 게임별 IP 체크리스트 (신규 게임마다 `packages/games/<id>/IP.md`로 작성)

```
2. 티어 판정: 🟢 / 🟡 / 🔴   근거: ______
3. 명칭 검색
   - KIPRIS (한국): 검색어 ______ 결과: 상표 등록 없음 / 있음(류·권리자 ______)
   - USPTO/TESS (미국): 검색어 ______ 결과: ______
   - 서비스 내 표기명 (ko/en): ______ / ______
4. 표현물 자체 제작 확인
   - [ ] 판 그래픽 자체 제작   - [ ] 말·토큰 자체 제작   - [ ] 아이콘 자체 제작
   - [ ] 규칙 설명문 자체 작성 (타 사이트 문장 복제 없음)
   - [ ] 효과음 자체 제작 또는 CC0 (출처 기록)
5. 외부 코드·엔진: 사용 여부 ______  라이선스 ______  연동 방식(분리 프로세스/워커) ______
6. 규제: 사행성 요소(현금·환전 가능 재화) 없음 확인 [ ]
```

## 6. 서비스명·브랜드

- 서비스명 확정 전 KIPRIS(제9류 소프트웨어, 제41류 온라인 게임 서비스)와 USPTO 검색.
- 도메인·SNS 핸들 동시 확보.
- 자체 게임 아이콘·로고는 제작 원본(SVG 소스)을 저장소에 두어 저작권 귀속을 명확히.

## 7. 오리지널 게임 트랙 (Phase 3) 가이드

현대 보드게임의 **추상 메커니즘**(자원 모아 카드 획득 → 구매력 누적, 숨은 역할 + 상이한 승리 조건 등)에서 출발하되:
- 이름·세계관·아트·카드 텍스트·수치 구성·판 형태를 전부 새로 설계
- 원작의 카드 목록·수치 표를 옮겨 적지 않음 (구체적 구성의 조합은 표현으로 판단될 수 있음)
- 출시 전 원작과의 "실질적 유사성" 관점에서 변호사 검토
- 인기 상업 게임은 성장 뒤 정식 라이선스 협상 트랙으로 분리
