# ADR-0002: 보드는 SVG로 렌더링

- 상태: 채택 (2026-09)
- 맥락: 체스 64칸부터 바둑 361점까지. 접근성(키보드·화면 리더), 선명도, 테마 전환, 구현 단순성이 중요. 초당 수십 프레임의 실시간 렌더는 필요 없다.
- 결정: React + SVG. viewBox 단위 좌표, `symbol/use`로 말 재사용, 프리미티브만 사용(HTML/foreignObject 금지).
- 대안: Canvas/PixiJS (성능 여유는 크지만 접근성·테마·히트 테스트를 직접 구현해야 함). 
- 결과: 바둑 19줄 361개 요소도 React 재조정 비용 무시 가능(메모이제이션). react-native-svg 이식 경로 확보. 대량 애니메이션이 필요한 게임이 생기면 그 게임만 Canvas 렌더러 선택 가능하도록 `BoardSurface` 뒤에 렌더러 인터페이스를 둔다.
