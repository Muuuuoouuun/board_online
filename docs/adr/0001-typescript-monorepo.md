# ADR-0001: TypeScript 단일 언어 모노레포

- 상태: 채택 (2026-09)
- 맥락: 규칙 로직을 서버(검증)와 클라이언트(힌트·AI·로컬 대국)가 모두 실행해야 한다. 언어가 갈리면 규칙을 두 번 구현하고 두 번 틀린다.
- 결정: 전부 TypeScript. pnpm workspaces + Turborepo. 게임별 패키지, `exports`로 rules/ai/ui 엔트리 분리.
- 대안: Go/Rust 서버 + TS 클라 (성능은 좋지만 규칙 중복), WASM 공유(빌드 복잡도 과함).
- 결과: 서버 성능은 턴제 특성상 충분. 규칙 패키지는 의존성 0으로 유지해 어디서든 실행.
