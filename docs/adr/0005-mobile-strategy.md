# ADR-0005: 모바일은 웹 우선 → PWA → Capacitor

- 상태: 채택 (2026-09), Phase 3에서 재평가
- 맥락: 우선 웹만. 다만 나중에 앱 스토어 존재감과 푸시 알림(내 차례)이 필요해질 것.
- 결정:
  1. MVP: 모바일 브라우저에서 완전히 동작하는 반응형 웹 (보드 375px, 터치 44px, 바텀 시트).
  2. Phase 2: PWA (설치, 오프라인 AI 대국·학습 페이지, 웹 푸시).
  3. Phase 3: Capacitor로 동일 웹앱 래핑 → iOS/Android 스토어. 네이티브 플러그인은 푸시·결제만.
  4. Expo/React Native 재작성은 Capacitor로 부족한 명확한 이유가 생길 때만.
- 지금부터 지키는 것: 보드 UI는 SVG 프리미티브만 사용(react-native-svg 이식 가능), 규칙·AI는 DOM 무관, 브라우저 전용 API는 `apps/web` 어댑터 층에만.
- 결과: 모바일 코드 중복 없음. 스토어 심사에서 "단순 웹 래퍼" 지적을 피하려면 오프라인 AI 대국·푸시·햅틱 등 앱다운 기능을 Capacitor 단계에서 포함.
