# 01. 제품 정의 — 비전, 범위, 카탈로그

## 1. 한 줄 정의

> 브라우저에서 링크 하나로 바로 두는 고전 보드게임 플랫폼. 로그인 없이 30초 안에 첫 수를 둘 수 있고, 계정을 만들면 게임별 레이팅과 기록이 쌓인다.

## 2. 왜 만드는가

- 체스는 lichess/chess.com, 바둑은 타이젬/KGS처럼 **게임별로 사이트가 갈라져** 있다. 장기·오목·윷놀이·고누는 제대로 된 웹 서비스가 드물다.
- 규칙이 공개된 고전 게임은 IP 리스크가 낮아 **한 엔진으로 다수 게임을 빠르게 쌓을 수 있다**.
- 한국 전통 게임(장기·윷놀이·고누)은 국내 차별점이자 해외에는 "새로운 게임"이다.

## 3. 타깃 사용자 (MVP)

| 페르소나 | 상황 | 핵심 요구 |
|---|---|---|
| 친구와 한 판 | 카톡으로 링크 보내서 바로 두고 싶음 | 로그인 없음, 링크 입장, 모바일 브라우저에서도 됨 |
| 혼자 연습 | 규칙을 막 배웠거나 시간 때우기 | AI 상대, 규칙 설명, 되돌리기 |
| 실력 경쟁 | 레이팅을 올리고 싶음 | 랜덤 매칭, 시계, 공정한 규칙, 기록 |
| 가족/교육 | 아이와 윷놀이·고누 | 같은 기기 2인, 큰 터치 영역, 쉬운 규칙 |

## 4. MVP 범위 (웹 전용)

### 반드시 포함 (Must)
- 게임 8종: 오목, 고누, 체커, 만칼라, 체스, 장기, 윷놀이, 바둑
- 플레이 모드 4종: **친구 초대(링크)**, **AI 상대(레벨 1~2)**, **같은 기기 2인**, **랜덤 매칭(게임별 단일 큐)**
- 게스트 플레이 (닉네임만 입력) + 선택적 계정 (이메일/소셜)
- 대국 시계 (없음 / 절대시간 / 피셔 증가)
- 기권, 무승부 제안, 재대국
- 끊겨도 다시 붙는 재접속 (같은 기기, 같은 브라우저 기준)
- 기보 저장과 리플레이 (수 단위 앞뒤 이동)
- 게임별 레이팅 (Glicko-2, 랜덤 매칭 대국만 반영)
- 게임마다 30초 규칙 설명 페이지
- 한국어 / 영어

### 포함하지 않음 (Won't, MVP 이후)
- 친구 목록, 클럽, 채팅(대국 중 정형 메시지 "잘 부탁합니다/좋은 수/감사합니다"만 제공)
- 관전, 토너먼트, 시즌
- 강한 AI (외부 엔진 연동)
- 모바일 앱 스토어 배포
- 자체 오리지널 게임, 라이선스 게임

## 5. 게임 카탈로그와 IP 티어

티어 기준은 `docs/06-ip-policy.md` 참고. 🟢 바로 구현, 🟡 명칭·권리 확인 후 구현, 🔴 라이선스 없이는 구현하지 않음.

### MVP 8종 (모두 🟢)

| 게임 | 규칙 기준 | 판 | 특이사항 |
|---|---|---|---|

## 6. 화면 목록 (MVP)

| # | 화면 | 경로(안) | 핵심 요소 |
|---|---|---|---|
| 1 | 홈/로비 | `/` | 게임 카드 그리드, "빠른 대국" 버튼, 진행 중인 내 대국, 오늘의 게임 |
| 2 | 게임 상세 | `/g/[gameId]` | 30초 규칙, 플레이 모드 4개 버튼, 시간 설정, 내 레이팅 |
| 3 | 대국 | `/play/[roomId]` | 보드, 두 플레이어 카드+시계, 수 목록, 액션 바(기권/무승부/재대국), 정형 메시지 |
| 4 | 초대 링크 랜딩 | `/join/[roomId]` | 게임·상대·시간 요약, 닉네임 입력 → 입장 |
| 5 | 결과 & 리플레이 | `/replay/[matchId]` | 결과 요약, 레이팅 변동, 수 단위 이동 슬라이더, 공유 링크 |
| 6 | 프로필 | `/u/[handle]` | 게임별 레이팅 칩(`Chess 1321 · Janggi 1510 · …`), 최근 대국 |
| 7 | 규칙 배우기 | `/learn/[gameId]` | 30초 요약 → 인터랙티브 연습 → 초급 AI 대국 |
| 8 | 로그인/가입 | `/auth/*` | 이메일 매직링크 + Google. 게스트 기록 승계 안내 |
| 9 | 설정 | `/settings` | 테마(라이트/다크/시스템), 사운드, 언어, 보드 스킨, 확인 후 착수 옵션 |

## 7. 핵심 사용자 흐름

```
[홈] → 게임 카드 클릭 → [게임 상세] → "친구 초대"
   → 방 생성(시간 설정) → 초대 링크 복사 → 상대가 [초대 랜딩] 에서 닉네임 입력
   → 양쪽 [대국] 진입 → 첫 수 → … → 종료 → [결과] → "재대국" or 홈
```

- 목표: 홈 진입부터 첫 수까지 **30초 이내**, 클릭 5회 이내.
- 초대 링크는 닉네임 입력 외 아무것도 요구하지 않는다.
- 게스트 상태에서 둔 대국은 브라우저에 묶인 게스트 id에 저장되고, 나중에 가입하면 승계된다.

## 8. 성공 지표 (MVP 출시 후 8주)

| 지표 | 목표 | 왜 |
|---|---|---|
| 초대 링크 → 대국 시작 전환율 | ≥ 60% | 링크 입장 마찰 측정 |
| 대국 완주율 (정상 종료 / 시작) | ≥ 75% | 이탈·버그·재접속 품질 |
| 재접속 성공률 | ≥ 95% | 모바일 브라우저 끊김 대응 |
| 게스트 → 계정 전환율 | ≥ 10% | 레이팅·기록의 매력 |
| 게임당 규칙 버그 신고 | 0건/주 (출시 4주 후) | 규칙 정확성이 신뢰의 전부 |
| 2개 이상 게임을 둔 사용자 비율 | ≥ 30% | "플랫폼"으로 작동하는지 |
