# 구현 및 검증 — 로컬 2인 우선

## 범위

`origin/claude/ai-opponent`의 6061231을 바탕으로 `codex/ai-opponent-material-design`에서 이어 작업했다. 사용자 정정에 따라 로컬 모드의 프론트엔드와 질감만 우선 개발했다. AI 엔진, worker, AiPlay 로직에는 변경이 없다. 공용 보드·색상·소리 버튼 스타일은 다른 기존 모드에도 적용된다. 이번 검증은 온라인 서버나 AI 대전 검증을 포함하지 않는다.

## 생성물

내장 Image Gen으로 로비·대국 시안 2장, 실사용 이미지 3종을 생성했다. 모델 선택 매개변수는 도구에 없으며 자동 선택된다. 전체 프롬프트는 `prompts.md`, 채택한 시안과 사용자 수정 사항은 `design-spec.md`에 기록했다.

`packages/client/public/art/`의 실사용 WebP:

- `table-still-life.webp`: 메인 보드게임 정물 사진, 246,370 bytes.
- `game-atlas.webp`: 게임 9종 사진 아틀라스, 307,992 bytes.
- `ash-wood.webp`: 원목 표면 질감, 143,922 bytes.

PNG 생성 원본을 WebP로 압축해 세 자산의 총 크기를 약 7.8MB에서 698KB로 줄였다. 사진 내용은 수정하지 않았다. 아틀라스는 CSS에서 각 게임에 맞는 셀을 표시한다.

## 시안과 실화면 비교

Codex 내장 브라우저(IAB)에서 직접 실행·클릭·드래그하고 캡처했다. 별도 Playwright 브라우저로 대체하지 않았다. 로비 시안의 1422×1106, 대국 시안의 1505×1045 뷰포트와 모바일 390×844를 요청해 확인했다. IAB는 저장 이미지의 크기를 조정하거나 스크롤바를 제외하기 때문에 PNG 픽셀 크기는 뷰포트 설정과 다를 수 있다. 실제 DOM 치수와 수평 넘침 여부를 함께 확인했다. 시안과 최신 캡처 모두 `view_image`로 열어 비교했다.

| 비교 항목 | 확인 및 수정 |
| --- | --- |
| 레이아웃 | 로비의 브랜드 바 → 좌측 제목/우측 사진 → 방 입장 → 게임 선택 순서 유지. 대국은 큰 보드와 우측 패널. 공용 CSS가 보드를 560px로 제한하던 충돌을 수정했다. |
| 글꼴/위계 | 한국어 명조 제목, 고딕 조작부, 큰 제목과 조용한 보조 문구. 모바일 플레이어 설명을 선공으로 줄여 불필요한 줄바꿈을 해결했다. |
| 색 | 따뜻한 아이보리, 짙은 올리브, 차콜 텍스트. 보조 텍스트 대비를 보강했다. |
| 질감/사진 | 생성 원목 이미지를 보드 밑에 배치하고 돌의 강한 광택을 줄였다. 썸네일의 강제 종횡비 왜곡을 수정해 원본 비율로 크롭한다. 사진은 별도 실사용 생성물이라 시안의 소품 구도와 동일하지 않다. |
| 컨트롤 | 전역 모드 선택, 분류 필터, 각 게임의 단일 시작 동작. 장기 시작 배치 기능 유지. 같은 화면을 기본값/첫 항목으로 지정했다. |
| 반응형 | 모바일에서는 영웅 이미지·입장 폼·게임 목록을 세로로, 대국에서는 보드를 먼저 배치. 모든 9종 로컬 화면에서 수평 넘침 없음. |
| 문구 | 첫 화면의 제목·메뉴·섹션명은 유지. 사용자의 로컬 우선 지시에 따라 CTA를 둘이서 한 판으로, 설명을 하나의 화면, 마주 앉은 두 사람으로 변경. 같은 화면이 활성화될 때 난이도 대신 한 기기에서 번갈아 두기를 표시. |

의도적 차이: 게임 시안의 AI 패널은 로컬 플레이어와 화면 전달 안내로 대체했다. 로고는 로비의 네 칸 마크로 통일했다. 시안이 임의로 만든 장식 문구·화분은 제외했다. 실제 엔진의 선수 이름과 보드 격자를 따른다. 장기 배치 선택을 보존하므로 카드 높이는 시안보다 높다. 색·서체·재료·배치의 시안 방향을 구현 화면과 대조해 검증했으며 픽셀 단위 동일 복제는 아니다.

## 실제 동작

- 로비: 기본 로컬 모드, 게임 9개, 전통 필터(4개)와 전체 복귀, 로컬 시작 링크.
- 오목: 양쪽 교대 착수, 5목 승리 모달, 다시 하기, 애니메이션 종료 후 말 0개로 초기화, 규칙 열기/닫기, 음소거 전환.
- 장기: 마상상마 배치 선택, 말 32개 유지, 초의 합법수 이동 후 한 차례 전환.
- 체스·체커·리버시·고누: 실제 말 선택/배치 및 상대 차례 전환.
- 윷놀이: 윷 던지기 → 걸(3) → 대기 말 진입 → 백 차례.
- 땅따먹기(선): 합법 셀 클릭 후 경로와 다음 합법 셀 변경.
- 땅따먹기(돌): 실제 드래그 후 남은 튕기기 3→2.
- 화면 전환 후 이전 스크롤 위치가 남는 문제 수정. 로비 복귀 시 scrollY=0 확인.
- React 18의 fetchPriority 속성 경고를 제거하고 새로고침 후 같은 경고가 추가되지 않음을 확인.
